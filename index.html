FAQ

常见问题 与解决办法

安装、权限、播放与缓存相关的高频问题，点开即可查看处理方式。

安装时提示"禁止安装未知来源应用"怎么办？
这是安卓系统的安全限制。进入 设置 → 应用管理 → 特殊应用权限 → 安装未知应用，找到你正在使用的浏览器或文件管理器并允许即可。不同品牌手机菜单名称略有差异，也可在设置中直接搜索"安装未知应用"。
影视大全 App 是否收费？有哪些限制？
基础观影与下载功能免费使用，部分独家内容或更高清晰度可能需要会员权益。具体会员价格、权益与自动续费规则以应用内"会员中心"页面展示为准，请以实际页面说明为准。
投屏搜不到设备，或投屏后经常断开？
请确认手机与电视/盒子处于同一局域网；关闭 VPN 与私人 DNS；重启路由器后重试。部分老旧电视盒子需在设备端手动开启 DLNA 服务。若仍无法连接，可尝试在应用内切换投屏协议。
离线缓存失败、进度不保存怎么处理？
先检查存储空间是否充足，并在系统设置中确认已授予应用存储权限。建议清理缓存队列中状态异常的条目后重新添加；跨版本升级后出现异常，可尝试卸载重装并重新登录账号以恢复云端进度。
为什么有些视频只有标清或无法播放？
清晰度受片源与版权授权范围影响，不同地区、不同剧集可提供的清晰度并不一致。播放异常时可尝试切换线路、切换清晰度，或清除播放器缓存后重试。
安装包安全吗？如何确认是官方版本？
建议只从影视大全官方下载页或官方应用商店获取安装包。安装前可比对页面标注的版本号、包名与签名信息；如系统安全软件提示风险，请先核对来源，避免安装来路不明的修改版或破解版。
隐私方面会收集哪些数据？
应用仅申请实现核心功能所必需的权限，如存储（用于缓存）、通知（用于更新提醒）等。详细的个人信息收集、使用与第三方 SDK 清单，请查看应用内《隐私政策》；不需要的权限可在系统设置中随时关闭。
